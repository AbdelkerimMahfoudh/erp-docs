## 2. App Store Connect — the owner's checklist (none done)

### Account and record
- [ ] Apple Developer Program membership for **TSX-MR** (organization; D-U-N-S number).
- [ ] App record: name **Dukan ERP**, bundle id `mr.tsxmr.dukanerp`, SKU, primary language, seller **TSX-MR**.
- [ ] EAS project `dukan-erp` linked (`docs/44` store identity, step 2) and `lib/app-identity.test.ts` updated in the same commit.
- [ ] EAS iOS credentials (distribution certificate, provisioning profile) generated by EAS under the Apple team.
- [ ] `EXPO_PUBLIC_API_ORIGIN` set as an **EAS environment variable** of the `production` profile: the https staging API (internal TestFlight) — never the shop's live database for testers.

### Build metadata
- [ ] Icon 1024×1024 from the approved logo (O-A1); `app.json` `icon` set.
- [ ] Export compliance: the app uses only the OS's HTTPS and Keychain. Confirm, then set `ios.config.usesNonExemptEncryption: false` (O-A3).
- [ ] iPhone only, or iPad too (O-A2). If iPad stays: iPad screenshots and an iPad review pass.

### TestFlight
- [ ] **Internal testing** (no Beta App Review): add internal testers (App Store Connect users of the team).
- [ ] **External testing** needs **Beta App Review**, which applies the guidelines: test information, a contact, a **demo business account** (a QA boutique on the staging API, with its MFA-free Owner login) and review notes.

### App Store (later)
- [ ] Privacy Policy URL — the website's `/privacy` exists **as a draft awaiting legal review** (`docs/74` B-2).
- [ ] In-app access to the privacy policy (guideline 5.1.1(i)). The app currently has **no link to any website by product rule** → owner decision O-A5 (e.g. the policy text inside the app, or one allowed link).
- [ ] App Privacy ("nutrition label"): data collected — contact info (email/phone of staff), user content (business records), identifiers (device id for session binding), usage of camera/photos on device only. Written by the owner from `docs/64`.
- [ ] Account deletion inside the app (5.1.1(v)) — exists; completing it needs a delivery channel in production (D116; WhatsApp postponed, email provider not chosen) → **blocks App Store review**.
- [ ] Business model (3.1.1 / 3.1.3(c)): D118 — business accounts only, no purchase in the app. Review notes say so.
- [ ] Age rating, category (Business), support URL, marketing URL (optional), copyright "TSX-MR".
- [ ] Screenshots: 6.9" and 6.5" iPhone (and iPad if kept), in each submitted language.
- [ ] Localizations: EN, FR, AR names/descriptions/keywords.
